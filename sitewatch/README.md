# SiteWatch Bot

Telegram-бот мониторинга доступности сайтов.

## Запуск

1. Установи зависимости:
   pip install -r requirements.txt

2. Задай токен бота:
   export BOT_TOKEN=your_token_here

3. Запусти:
   python bot.py

## Деплой на Railway

1. Создай проект на railway.app
2. Добавь переменную BOT_TOKEN
3. Деплой через GitHub или CLI
